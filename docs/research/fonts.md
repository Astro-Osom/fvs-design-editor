# Fonts: where they come from and what may be shared

Research for adding fonts beyond the five built-in families. Everything marked "checked" was verified on 20 November 2026 against the service or file itself, not from memory.

## The question

Can every font on the owner's computer, and every Google font, be loaded into the editor?

- **Installed fonts:** they can be *used* on the computer they are installed on. They cannot be copied into the app or this public repository, because most are licensed (Apple, Microsoft, Adobe and others). The Mac this was built on has 356 installed families (994 font files), including commercial ones.
- **Google Fonts:** every family is openly licensed, so there is no legal obstacle. There are about 1,960 families, far too much to ship inside the app, so a family is downloaded the first time it is used and kept on the machine after that.

## Google Fonts

### Licences

Google Fonts uses three licences. All three allow use, redistribution and embedding, including commercially, which is what makes it possible to put a Google font's files inside a project file.

| Licence | Families in the catalogue | Notes |
|---|---|---|
| SIL Open Font License 1.1 (`OFL-1.1`) | 1,920 | Copies must keep the copyright notice and licence. The font may not be sold by itself. A modified font may not use a reserved name. |
| Apache License 2.0 (`Apache-2.0`) | 35 | Copies must keep notices. |
| Ubuntu Font Licence 1.0 (`UFL-1.0`) | 5 | Similar to the OFL. |

How each family's licence was confirmed (checked):

- The [google/fonts](https://github.com/google/fonts) repository keeps each family in a folder named for its licence: `ofl/`, `apache/` or `ufl/`. This is the primary source.
- The [Fontsource API](https://api.fontsource.org/v1/fonts?type=google) lists a licence for each family and was used as a second opinion. The two sources did not disagree for any family.
- A family whose licence could not be confirmed is left out. One family (Molle) is left out for a different reason: it has italics only.

The editor never changes a font file. It stores exactly the bytes Google serves and puts those same bytes in the project file. Two files as served by Google were opened and inspected (Lobster and Roboto, checked): both still carry the copyright notice and the licence address in their name table, and both have embedding permission set to "installable". So the notices the OFL requires travel with every copy, and the reserved-name rule (which applies to modified fonts) does not come into play. The project file's manifest also records each font's licence identifier.

### Where the list of families comes from

The list (family name, category, which weights and italics exist, licence, and a flag for very large families) is generated by `scripts/update-google-fonts-catalogue.mjs` and committed as `src/fonts/google-catalogue.json`. It is 55 KB (16 KB compressed), contains no font data, and is loaded only when the font menu is opened. Shipping it means browsing and searching work with no network.

| Source | Used for | Needs a key | Readable from a web page |
|---|---|---|---|
| `https://fonts.google.com/metadata/fonts` | Families, categories, styles, popularity order | No | No (it sends no cross-origin header), so it is read by the script, not by the app |
| `https://api.github.com/repos/google/fonts/git/trees/main` | Licence of each family | No | Not needed |
| `https://api.fontsource.org/v1/fonts?type=google` | Second opinion on licences | No | Yes |

The first of these is not a documented API. If it changes, only the script breaks; the app keeps working with the list it shipped with. Google's documented list API (the Developer API) needs a key, which is why it is not used.

### Where font files come from

At run time the app contacts exactly two hosts, and only when the person picks a Google font (or turns on previews):

| Host | What is fetched | Checked |
|---|---|---|
| `https://fonts.googleapis.com/css2` | A stylesheet listing the family's font files | No key. Sends `Access-Control-Allow-Origin: *`. Unknown family answers 400. |
| `https://fonts.gstatic.com` | The font files (WOFF2) | Sends `Access-Control-Allow-Origin: *`. |

Things worth knowing about the stylesheet service (all checked):

- It answers differently depending on the browser. Chrome, the desktop app (Electron 45) and Firefox get WOFF2 files split by groups of characters ("latin", "cyrillic" and so on). An unrecognised client gets one TrueType file per style. The parser handles both.
- The same file can serve several weights (variable fonts). Files are stored once, by the hash of their bytes.
- Sizes vary a lot: Lobster is 5 files, Roboto 18, Poppins 54, Noto Sans JP 124. The 135 families that cover Chinese, Japanese or Korean are flagged "Large download" in the menu.
- Adding `&text=Lobster` returns a tiny file containing only those letters. This is used for the optional previews.

Both hosts are already on the default allowed list of the project's cloud environment.

### Decisions

- **Download the whole family** (every weight, italic and character group) when it is first used, so that changing weight or typing in another script later never needs the network. The alternative, fetching pieces as needed, would make an offline machine fail in the middle of editing.
- **Pin the exact files in the design.** Google updates fonts over time. A design records the hash of each file it uses, so it is drawn with the same font data everywhere, even if another machine has a newer copy of the same family.
- **Previews are off by default.** Showing 1,960 names in their own fonts means asking Google for each one as it scrolls into view. That is the person's choice to make, so it is a clearly labelled tick box.

## Fonts installed on the computer

### Listing them

The Local Font Access API (`window.queryLocalFonts()`) lists installed fonts after the person gives permission.

| | Result (checked) |
|---|---|
| Chrome 158 | Available. Returns nothing until permission is granted. |
| Desktop app (Electron 45, Chromium 156) | Available. Permission is decided by the app, which allows this one permission and refuses all others. |
| Firefox, Safari | Not available. "Add a font file" is offered instead. |
| Speed | The first call in a session took 18 to 42 seconds on a Mac with 994 font files. Later calls are instant. |
| Quitting | The desktop app cannot quit until a listing in progress has finished (measured: 29 seconds). So fonts are listed only when the person asks for them in the font menu, never by themselves, and the menu says the first time can take a minute. |
| Font data | `blob()` returns the font's bytes as TrueType or OpenType, so weight, italic and embedding permission can be read from the font itself. |

### Using them without copying

A face can be loaded by its exact system name, `local("PostScript name")`, without any permission, and loading fails cleanly when the font is not installed (checked). So a design keeps only the names of an installed font's faces. Reopening it on the same computer needs no permission and no question; on a computer without the font, the failed load becomes the missing-font warning.

### Embedding permission

A font file says what its maker allows in the `fsType` field of its `OS/2` table. A project file is an editable document that carries the whole font file, so the rule is strict:

| `fsType` | Meaning | Put inside a project? |
|---|---|---|
| 0 | Installable embedding | Allowed, if the person opts in |
| bit 3 (0x0008) | Editable embedding | Allowed, if the person opts in |
| bit 2 (0x0004) | Preview and print only | No: a project is edited, not just viewed |
| bit 1 (0x0002) | Restricted licence | No |
| bit 9 (0x0200) | Bitmap embedding only | No |
| table missing | The font does not say | No |

Even when the font allows it, the editor only embeds an installed or added font if the person ticks the box, and the box says to do so only for fonts they may share. The permission bits describe what the font's maker intended; they are not a substitute for the licence the person actually holds.

### Font files the person adds

`.ttf`, `.otf` and `.woff` files can be added. `.woff2` cannot: its contents are Brotli-compressed, and neither Chrome 158 nor Electron 45 offers pages a Brotli decoder (`new DecompressionStream('brotli')` is refused, checked), so the family name and embedding permission cannot be read. The message says to use the `.ttf` or `.otf` version. Font collections (`.ttc`) are refused because browsers cannot load one from data.

## What is never done

- No font from the owner's computer, and no font that is not openly licensed, is added to this repository or to the app.
- Nothing is uploaded. Google is contacted only to download.
- Test fonts come from the `@fontsource/lobster` and `@fontsource/pacifico` packages (OFL-1.1), installed as development dependencies. A font that forbids embedding is made during the test by changing one field of a copy in memory.

## Not checked

- Windows and Linux: how each lists installed fonts and whether `local()` matches the same names there.
- Firefox and Safari end to end. The code paths exist (no listing, add a file instead) but were not run in those browsers.
- Text in Chinese, Japanese or Korean. Downloading a large family was checked (Noto Sans JP through the running app: 124 files, 5.2 MB, 1.3 seconds, all nine weights offered), but no design was typed and exported in those scripts.
